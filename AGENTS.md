# Public Skill maintenance

This repository is the single source of truth for public Skills, including chestnut-copy. Edit skills/<skill-name>/ here. Independent repositories are generated distribution mirrors with separate Stars and Issues; never maintain Skill content there. Publishing is defined in .github/workflows/publish.yml and distribution/skills.json. Entries with mirror:false provide a standalone ZIP and inclusion in the bundle from this repository without a separate mirror or new deploy key. Preserve the old Copy repository URL and compatibility paths. Do not import private Chestnut content. Do not claim this collection covers all 云股东 courses until that audit is completed.
